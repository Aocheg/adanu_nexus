## ⚡ Features & Interactivity

1. **Sticky Glassmorphism Navbar**: Retains position on scroll with automatic elevation shadow.
2. **Desktop Dropdown Menu**: Smooth CSS transition dropdown for all four service practices.
3. **Off-Canvas Mobile Drawer**: Accessible hamburger menu with backdrop blur, trap focus, and escape key listener.
4. **Interactive Accordion FAQ**: Smooth expand/collapse animation for question-and-answer pairs.
5. **Dynamic Portfolio Filter**: Client-side JavaScript filtering by category (`All`, `Software`, `Design`, `Nursing`, `Mental Health`).
6. **Floating WhatsApp Quick-Chat**: Global sticky CTA widget with pulse hover effect for instant mobile engagement.
7. **Formspree Contact Integration**: Pre-wired form configuration pointing to direct inbox notification.

## 🚀 Deployment Instructions.

The codebase is 100% static (HTML, CSS, JS, assets) and requires no build step (`npm run build`), making it instantly deployable anywhere:

### 1. GitHub Pages (Free).
1. Push this repository to GitHub: `git push origin main`.
2. In your GitHub repository, navigate to **Settings** &rarr; **Pages**.
3. Under **Branch**, select `main` and root folder `/ (root)`.
4. Click **Save**. Your site will be live at `https://aocheg.github.io/adanu_nexus/`.

### 2. Vercel.
1. Log in to [Vercel](https://vercel.com) using your GitHub account.
2. Click **Add New** &rarr; **Project** &rarr; Select `adanu_nexus`.
3. Leave build settings default (Framework preset: `Other`).
4. Click **Deploy**.

### 3. Netlify
1. Log in to [Netlify](https://www.netlify.com).
2. Click **Import from Git** &rarr; Choose `adanu_nexus`.
3. Set publish directory to `.` (root).
4. Click **Deploy Site**.

### 4. Render
1. In the Render Dashboard, select **New Static Site**.
2. Connect your `adanu_nexus` repository.
3. Publish directory: `./`.
4. Click **Create Static Site**.
